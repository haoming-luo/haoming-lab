01 / MATERIAL MEMORY

Can a model learn
material memory?

A metal's stress depends on how it was loaded, not just its current strain. Change the loading path and see how DENIM predicts the response.

DENIM · Synthetic elastoplastic histories · Neural constitutive models

02 / STRUCTURAL DESIGN

How much lighter
could it be?

Removing material saves weight, but changes how a bracket deforms. Try different designs under the same load, or use the paired geometry and field data to train your own surrogate.

GINO-based models · 3D brackets · Precomputed demo results

03 / CONTROLLED HEAT

What happens when
the heating changes?

Start from the same temperature field, then keep heating, reduce power, or switch the source off. Use the resulting temperature histories to train a model that accounts for these changes.

64 scenarios · 192 trajectories · Temperature fields, controls & sensor readings

ABOUT AGENTFEM

Run your own simulations

AgentFEM is open-source finite-element software built on FEniCSx. Set up and run models with Python or the command line, or connect an AI assistant through MCP.
